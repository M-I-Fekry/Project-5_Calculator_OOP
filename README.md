# 🧮 Object-Oriented Calculator in C++

## 📘 Description  
This project is a simple **Calculator** implemented in **C++** as part of the 10th course on the [AbouHadhood Platform](https://programmingadvices.com/).  
The goal is to **demonstrate the principles of Encapsulation and Abstraction** using a single class.

The calculator performs essential arithmetic operations and introduces advanced control features like **undo last operation**, **clear results**, and **protection against division by zero**, ensuring reliable and safe execution.  

---

## ⚙️ Features
- ➕ Add numbers  
- ➖ Subtract numbers  
- ✖️ Multiply numbers  
- ➗ Divide numbers *(with zero protection)*  
- 🔁 Cancel last operation  
- 🧹 Clear all results  
- 💾 Display current and previous results  

---

## 🧠 Concepts Used
- **Classes and Objects**  
- **Encapsulation (Data Hiding)**  
- **Access Modifiers (Private/Public)**  
- **Method Reusability and Design**  
- **Basic Exception Prevention (Division by Zero)**
